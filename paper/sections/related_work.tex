% \paragraph{Single-image augmentation.}
% Standard image augmentations operate on one image at a time and preserve the
% original class label. Examples include geometric and photometric transformations
% as well as learned or randomized augmentation policies such as
% Cutout~\citep{devries2017cutout}, Random Erasing~\citep{zhong2020random},
% AutoAugment~\citep{cubuk2019autoaugment}, RandAugment
% \citep{cubukRandAugmentPracticalAutomated2019}, and AugMix~\citep{hendrycks2020augmix}. These
% methods improve invariance and robustness without changing the target space.
% Their limitation is that the training signal remains single-source: the model
% only observes one labeled image per augmented example and receives one hard
% target. Consequently, such augmentations cannot construct examples whose target
% depends on multiple labeled sources, nor can they control the relative amount
% of supervision assigned to several simultaneously visible classes.

% \paragraph{Pairwise mixed-sample augmentation.}
% Mixed-sample augmentation changes this setting by combining two training
% examples and assigning a mixed target. Mixup~\citep{mixup}
% interpolates two images and their one-hot labels,
% \(
%     \tilde{x} = \lambda x_i + (1-\lambda)x_j,
%     \tilde{y} = \lambda y_i + (1-\lambda)y_j .
% \)
% Here the label weights are inherited from the interpolation coefficient rather
% than from a spatial layout. CutMix~\citep{cutmix} instead composes two
% images spatially by replacing a region of one image with a patch from another;
% the target keeps the same convex form, but $\lambda$ is computed from the
% visible image area. This area-based target construction is also used or refined
% by many later pairwise methods. ResizeMix~\citep{qin2020resizemixmixingdatapreserved} resizes
% pasted content before insertion, FMix~\citep{harris2021fmixenhancingmixedsample} uses
% Fourier-sampled binary masks, GridMix~\citep{baekGridMixStrongRegularization2021} mixes images
% through grid-like regions, and PuzzleMix~\citep{kim2020puzzlemixexploitingsaliency} optimizes patch
% placement using saliency information. Other pairwise methods refine the label
% estimate rather than only the mask: SnapMix~\citep{huang2020snapmixsemanticallyproportionalmixing} uses class
% activation maps to estimate semantic contribution, TransMix
% \citep{chen2021transmixattendmixvision} uses transformer attention to adjust CutMix labels,
% and TokenMix~\citep{liu2023tokenmixrethinkingimagemixing} performs token-level mixing for vision
% transformers. Thus, pairwise methods refine how two sources are mixed and how their two-way
% target weight is estimated, but they cannot express a controlled distribution
% over more than two present labels, motivating multi-image augmentation.

% \paragraph{Multi-image augmentation.}
% A smaller line of work composes more than two images. RICAP
% \citep{takahashiDataAugmentationUsing2020} crops four images and patches them into one canvas,
% using the crop areas as soft-label weights. Mosaic augmentation, popularized in
% YOLOv4~\citep{bochkovskiyYOLOv4OptimalSpeed2020}, similarly combines multiple images into a single
% detection example and adjusts the annotations to the composed layout.
% Cut-thumbnail~\citep{Xie_2021} inserts resized thumbnail content
% into another image, StackMix~\citep{chen2022stackmix} studies stacked
% compositions, DCutMix~\citep{jeong2022dcutmix} expands CutMix to more than two
% images, k-Mixup~\citep{greenewald2023kmixupregularizationdeeplearning} generalizes mixup to multiple
% samples through optimal-transport interpolation, and MixMo
% \citep{rame2021mixmo} mixes multiple inputs in a multi-input multi-output
% architecture.

% These methods show that multi-source examples can expose richer visual
% variation than pairwise augmentation. However, their control over the composed
% sample is limited in different ways. RICAP~\citep{takahashiDataAugmentationUsing2020} and
% Mosaic~\citep{bochkovskiyYOLOv4OptimalSpeed2020} use a fixed small number of sources and restricted
% layout families. DCutMix~\citep{jeong2022dcutmix} obtains multi-image mixtures
% through repeated CutMix-style operations rather than by sampling one coherent
% $K$-way area distribution. k-Mixup~\citep{greenewald2023kmixupregularizationdeeplearning} provides a
% multi-sample interpolation method, but it does not create explicit visible
% regions whose areas define the supervision. MixMo~\citep{rame2021mixmo}
% requires a multi-input/multi-output model interface, whereas a drop-in
% augmentation should preserve the standard single-input classifier. TreemapMix
% therefore uses a model-independent single-input construction: a Dirichlet draw
% defines the full $K$-way composition, and a treemap partition realizes the
% sampled weights as area-proportional image regions.

% Most multi-image composition methods also use the same target interpretation as
% spatial pairwise mixing. If source $k$ occupies visible area $\lambda_k$, the
% mixed target is typically
% \(
%     \tilde{y} = \sum_{k=1}^{K} \lambda_k y_k ,
% \)
% which treats area as a calibrated class-probability target. This is convenient,
% but it is stronger than what the geometry strictly implies: a large region may
% contain background, while a smaller region may contain a discriminative object
% part. Calibration- and ranking-oriented mixup methods such as
% SmoothMixup~\citep{jeong2021smoothmixtrainingconfidencecalibratedsmoothed}, RegMixup~\citep{pinto2023regmixupmixupregularizersurprisingly},
% and RankMixup~\citep{noh2023rankmixuprankingbasedmixuptraining} study related limitations of mixed
% targets. TreemapMix uses the known region areas in two ways. The soft
% cross-entropy variant follows the conventional area-weighted interpretation,
% whereas the Plackett--Luce variant uses the same areas only as ordinal
% supervision. Thus, the number of sources, region geometry, and target
% interpretation are controlled separately rather than being fixed by a
% particular mixing heuristic.

 \section{Related Work}

Standard augmentations preserve the original label, including region dropout
methods such as Cutout and Random Erasing~\citep{devries2017cutout,
zhong2020random} and policy-based methods such as AutoAugment, RandAugment,
and AugMix~\citep{cubuk2019autoaugment,
cubukRandAugmentPracticalAutomated2019,hendrycks2020augmix}. Pairwise
mixed-sample methods instead combine two examples and assign mixed targets:
Mixup~\citep{mixup} interpolates images and labels, while CutMix~\citep{cutmix}
uses spatial replacement with area-based labels. Later methods refine pairwise
composition or label estimation through resized patches, Fourier masks, grids,
saliency, class activation maps, attention, or token-level mixing~\citep{
qin2020resizemixmixingdatapreserved,harris2021fmixenhancingmixedsample,
baekGridMixStrongRegularization2021,kim2020puzzlemixexploitingsaliency,
huang2020snapmixsemanticallyproportionalmixing,
chen2021transmixattendmixvision,liu2023tokenmixrethinkingimagemixing}.
These methods improve label-preserving or two-source augmentation, whereas
TreemapMix constructs multi-source examples with a controllable distribution
over more than two visible labels.

\paragraph{Multi-image augmentation and label supervision:}
Multi-image augmentations compose more than two sources, including RICAP, which
patches four crops with area-weighted labels~\citep{
takahashiDataAugmentationUsing2020}, Mosaic augmentation in detection
pipelines~\citep{bochkovskiyYOLOv4OptimalSpeed2020}, Cut-thumbnail
~\citep{Xie_2021}, StackMix~\citep{chen2022stackmix}, and
DCutMix~\citep{jeong2022dcutmix}. Other methods generalize mixing beyond
spatial layouts, such as k-Mixup through optimal-transport interpolation
~\citep{greenewald2023kmixupregularizationdeeplearning} and MixMo through a
multi-input multi-output architecture~\citep{rame2021mixmo}. TreemapMix is
closest to spatial multi-image methods such as RICAP and Mosaic, but samples a
single coherent $K$-way area distribution from a Dirichlet distribution and
realizes it as an area-proportional treemap layout; unlike k-Mixup and MixMo,
it remains spatially explicit and uses a standard single-input model interface.
Most spatial mixing methods treat visible area as a calibrated soft-label
weight, although area may be an imperfect proxy for semantic evidence. Related
work studies confidence and target behavior under mixup-style training through
SmoothMixup~\citep{jeong2021smoothmixtrainingconfidencecalibratedsmoothed},
RegMixup~\citep{pinto2023regmixupmixupregularizersurprisingly}, and
RankMixup~\citep{noh2023rankmixuprankingbasedmixuptraining}. Plackett-Luce
ranking has also been used for classification in PLD~\citep{pld}, but in a
knowledge-distillation setting where a teacher model provides the class ranking.
In contrast, TreemapMix induces the ranking directly from the mixed input: the
Dirichlet-sampled region areas define the area-induced ordering over target
classes. TreemapMix-SCE follows the area-weighted probability interpretation,
while TreemapMix-PL converts the same areas into ordinal supervision with a
Plackett-Luce ranking objective.
